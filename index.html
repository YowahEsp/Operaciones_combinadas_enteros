Operaciones combinadas · números enteros

En cada paso se hace la operación u operaciones que tienen prioridad, y las demás no se tocan.

Ejemplos:
  1. 1.º Paréntesis, corchetes y llaves
  2. 2.º Potencias y raíces
  3. 3.º Multiplicaciones y divisiones
  4. 4.º Sumas y restas
Dos signos seguidos +(+) = +−(−) = + +(−) = −−(+) = −
Multiplicar y dividir signos iguales: +signos distintos: −
Sumar y restar mismo signo: se suman y se deja el signo distinto signo: se restan y gana el signo del mayor

Los números negativos van entre paréntesis cuando están detrás de un signo: 3 · (−2). Para multiplicar se puede escribir ·, * o x; para dividir, : o /. Potencias: ^, por ejemplo (−2)^3, o las teclas x² y x³. Raíz cuadrada: √ o raiz, por ejemplo raiz 25. Con el teclado: → o Espacio avanza y ← retrocede.
